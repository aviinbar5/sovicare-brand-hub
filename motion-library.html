Every interaction pattern used on the website, playing live. The same 17 patterns are Figma Motion components in the working file (02.01 — Elements · 🎬 Motion demos) and sit next to each card in every Interactions panel.

The rule

Motion confirms, it never performs. One easing (ease), one distance (10px up), four durations. Selection is a 1.02 scale plus a border. With reduced motion switched on, every state appears instantly.
