Screens · Admin

The room behind the room.

Internal tools run on the same palette and the same mark, at a different density. A person looks at this screen for six hours, not six seconds, so nothing here is bigger than it needs to be.

Rule

The Tool variant

Admin and Support use the same colours and the same mark as the consumer product, and change four things. Nothing else is allowed to diverge — a tool that looks like a different company is a tool people distrust.

Density
13px body, 40px rows

Down from 15–16px. Row height 40px instead of 56 — more records per screen without shrinking hit targets below 32px.

Radius
12px cards, 8px fields

Half the consumer radius. Buttons stay fully round — that one thing carries the brand through.

Serif
Page title only

One DM Serif Display line per screen. Never on a table header, a stat, or a button.

Mono
IDs in JetBrains Mono

Opaque ids, order numbers, and codes only. Never prose — it is a data type, not a style.
